The files in stock/ and oxcaml/ (except import.ml, copied from this
directory) are generated by `make jsoo-imports` (also run by `make
jsoo-build`) from the js_of_ocaml subtree in this repository,
external/js_of_ocaml/compiler/lib. Do not edit them these directly.
Instead, you should edit the source directly and regenerate them using
the commands above. We can also run `make jsoo-imports-check` to
verify that they are up to date.

Generation runs JSOO's `ppx_optcomp_light`, which resolves the
[@@if ...] attributes, with the [oxcaml] predicate forced:
  - stock/  has [oxcaml] = false, and is the jsoo_imports library in the
    bootstrap build (dune context "default", stock OCaml compiler);
  - oxcaml/ has [oxcaml] = true, and is the library in every other context.
